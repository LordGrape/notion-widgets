# ADR-0006: V2 scope discipline

- Date: 2026-08-18
- Status: Accepted

## Decision

V2 is a structural programme only: no UI framework change, no deployment
change, no new features. The Vite single-file build artifact is
unchanged. Feature ideas are parked until Phase V5 completes.

## Rider (ratified with the decision)

A UI change remains a legitimate future consideration: deferred, not
forbidden. Revisit after Phase V5, when the codebase can absorb a
view-layer change safely. Any UI framework evaluation routes back
through the decision log.
