# Clock

## Purpose
Clock, stopwatch, timer, focus tracking, weather, and presence widget for Notion embeds.

## Current source
- Legacy production file: `../../clock.html`
- Shared runtime: `../../core.js`

## Migration status
This app folder currently wraps the legacy widget without changing behaviour. Keep edits focused:
- UI/runtime changes: edit `../../clock.html`
- Shared behaviour: edit `../../core.js`
- App-specific docs: edit this README

## Embed path
Use the root `clock.html` path until deployment is updated to serve `apps/clock/` directly.
